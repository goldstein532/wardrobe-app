# Запуск витрины: бот + GitHub

Всё бесплатно. Займёт около 20 минут. Нужен аккаунт GitHub и Telegram админа канала.

## Два режима чтения канала

| | `SOURCE=web` (сейчас) | `SOURCE=bot` |
|---|---|---|
| Права бота в канале | не нужны | админ (можно без прав) |
| Откуда посты | публичная лента `t.me/s/<канал>` | апдейты Telegram боту |
| Старые посты | читаются сами при первом запуске | нужен отдельный импорт |
| Фото | до 800 px | до 1280 px (HD — до 2560) |
| Посты, пересланные из express | не видны (Telegram их не показывает в ленте) | видны |
| «Доп фото» из комментариев | нет | да |
| Удалённые посты | замечает сам | только командой `/hide` |
| Ответ на пост «SOLD» / «бронь» | меняет статус | — (только правка поста или команда) |

Режим меняется переменной `SOURCE` в Settings → Secrets and variables → Actions → Variables.
В режиме `web` бот нужен только для команд админа в личке — шаг 1.3 можно пропустить.

## 1. Бот

1. Откройте @BotFather → `/newbot` → имя (например «Nasonchikh — витрина») и username (например `nasonchikh_shop_bot`).
2. Сохраните **токен**. Никому его не пересылайте и не вставляйте в код. Он понадобится только в шаге 3.
3. Добавьте бота **администратором**:
   - в канал **nasonchikh wardrobe**: право «Изменять сообщения» (для кнопок под постами);
   - в канал **nasonchikh express**: то же;
   - в **группу обсуждения** канала (там «Доп фото»): обычный админ без особых прав. Без админки бот не видит комментарии.

## 2. Репозиторий на GitHub

1. Создайте **публичный** репозиторий, например `wardrobe-app` (GitHub Pages бесплатен только для публичных).
   Публичными будут код и каталог товаров. Токен и id админов хранятся в секретах и не видны.
2. Загрузите туда эту папку (могу сделать сам, если вы войдёте в GitHub на этом компьютере).
3. **Settings → Pages → Build and deployment → Source: GitHub Actions.**

## 3. Секреты и настройки

**Settings → Secrets and variables → Actions.**

Вкладка **Secrets**:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | токен из шага 1 |
| `ADMIN_IDS` | Telegram id админов через запятую (см. шаг 5) |

Вкладка **Variables**:

| Имя | Значение |
|---|---|
| `CHANNEL_MAIN` | `nasonchikh_wardrobe` |
| `CHANNEL_TRANSIT` | username канала express |
| `ADMIN_USERNAME` | `nasonchikh_mngr` |
| `WEBAPP_URL` | `https://<ваш-логин>.github.io/wardrobe-app/` |

## 4. Первый запуск

**Actions → sync → Run workflow.** Через 1–2 минуты витрина откроется по адресу из `WEBAPP_URL`.
Дальше GitHub сам запускает синхронизацию каждые 5 минут.

Старые посты (до добавления бота) бот не видит. Их подтянет одноразовый импорт истории — отдельный этап.

## 5. Mini App в Telegram

1. Напишите боту `/whoami`, после ближайшей синхронизации он пришлёт ваш id → впишите в `ADMIN_IDS`.
2. @BotFather → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App** → URL = `WEBAPP_URL`.
   Так витрина откроется кнопкой «Открыть» в профиле бота и по ссылке `t.me/<бот>?startapp`.
3. @BotFather → **Bot Settings → Menu Button** → URL = `WEBAPP_URL`, текст «Витрина».

## Как пользоваться

- Пост с `#наличие` или `#едет` появляется в витрине через 5–15 минут.
- Продано → допишите в пост `#продано` (или перешлите пост боту и отправьте `/status N продано`).
- Перешлите боту любой пост из канала — он покажет, как распознал его, и подскажет команды.
- `/help` — список команд админа.

## Если что-то не работает

- **Витрина не обновляется.** Actions → sync → последний запуск → лог. Строки вида
  `nasonchikh_wardrobe/123: пропущен — нет #наличие…` показывают, какие посты не распознаны.
- **В логе `409 Conflict`.** У бота включён вебхук: откройте в браузере
  `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook` один раз.
- **Синхронизация остановилась сама.** GitHub выключает расписание в репозиториях без активности 60 дней:
  Actions → sync → «Enable workflow».
